# ЛК в2в — прототип раздела «Личный кабинет гостя»

Прототип раздела TravelLine Extranet «Управление гостями → Личный кабинет гостя» на компонентах Reactor.

## Экраны

- **Личный кабинет гостя** (`#/Settings`) — описание раздела, ссылка на ЛК (только чтение, берётся из админских настроек), настройки.
- **Настройки (admin)** (`#/AdminSettings`) — тип личного кабинета (TL или внешний), ссылка, вход в модуле бронирования. К основному кабинету можно добавить дополнительный — у любого отеля, признак сети не учитывается. Максимум один кабинет каждого типа: дополнительный всегда другого типа, чем основной.

Варианты сочетания ЛК: только ЛК TL; только внешний; ЛК TL + внешний; внешний + ЛК TL.

У каждого кабинета — «Ссылка на личный кабинет» (куда открыть кабинет) и «Используется на сайтах» (по адресу сайта GuestProfile выбирает, какой ЛК и какую настройку входа применить к ФБ). Сайты необязательны только для единственного ЛК TL; один сайт нельзя указать у двух кабинетов (сравнение без протокола, www и слэша в конце).

Вход в модуле бронирования TravelLine настраивается в блоке ЛК TL (по умолчанию включён). В блоке внешнего ЛК над ссылкой — алерт-предупреждение (warning) о том, что вход всегда скрыт. На странице гостя эта настройка не показывается.

## Запуск

Пакеты `@reactor/*` ставятся из внутреннего реестра компании, для установки нужен `.npmrc` с доступом к нему (в репозиторий не входит).

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 4175
```

## Обновление публикации

Прототип: https://polina-ko-dis.github.io/LK_B2B/

```bash
VITE_BASE_PATH=/LK_B2B/ npx vite build
rm -rf docs
cp -R dist/client docs
touch docs/.nojekyll
```

Закоммитьте исходники и `docs`, затем отправьте изменения в ветку `main`. GitHub Pages публикует каталог `docs`; доступ к частному реестру на стороне GitHub не требуется.

Макеты: Figma «Личный кабинет гостя В2В», страница «Настройки», секция «Реактор».
