# ЛК в2в — прототип раздела «Личный кабинет гостя»

Прототип раздела TravelLine Extranet «Управление гостями → Личный кабинет гостя» на компонентах Reactor.

## Экраны

- **Личный кабинет гостя** (`#/Settings`) — описание раздела, ссылка на ЛК (только чтение, берётся из админских настроек), настройки.
- **Настройки (admin)** (`#/AdminSettings`) — тип личного кабинета (TL или внешний), ссылка, вход в модуле бронирования; для сетевого отеля — основной и дополнительный ЛК.

Внизу экрана — панель для разработчика с переключателем «Одиночный отель / Сетевой отель». Она не часть интерфейса.

## Запуск

Пакеты `@reactor/*` ставятся из внутреннего реестра компании, для установки нужен `.npmrc` с доступом к нему (в репозиторий не входит).

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 4175
```
